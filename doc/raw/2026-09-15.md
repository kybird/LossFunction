## Case 7: Rust KIS 클라이언트 — 비동기 락의 이중 잠금 함정

### Grounding
- Git Context: 이 커밋
- Evidence: rust/lossfunction/src/kis/{auth,rest,rest_tests}.rs
- Confidence: 5/5

### Error (교착 2연발)
1. `access_token` 빠른 경로가 같은 tokio Mutex를 **조건식과 본문에서 두 번
   lock** — 캐시에 유효 토큰이 있는 순간부터 모든 호출이 영구 대기.
   해결: 단일 가드 블록 안에서 검사+반환.
2. 테스트의 `*clock.lock() = *clock.lock() + delta;` — **한 문장에서 같은
   std Mutex 이중 lock**(RHS 임시 가드가 문장 끝까지 생존). 해결: 두 문장으로
   분리.
교훈: Rust의 임시 수명 규칙(if 조건식/대입문)은 락에서 함정이다 — 락 가드는
**명시적 스코프 블록**으로 감싸고 한 문장 한 락을 지킬 것.

### Design Decision
- reqwest 기반(wiremock 계약 테스트): tokenP/KST/마진 갱신/401 무효화,
  order-cash 공식 형상(대문자 문자열 바디·tr_id·ODNO/ORGNO), rvsecncl 잔량
  전부 취소, 잔고 tr_cont 응답 헤더 M/F 페이지네이션, 시세 stck_prpr,
  ccld 행→ExecutionReport(누락 필드명 포함 실패).
- rt_cd!=0 → ApiReject(msg_cd 보존, 재시도 금지) — BrokerError::Rejected로
  연결돼 게이트웨이의 확정 거부 분기와 만난다.

### Verification
- `cargo test` → 81 passed (wiremock 형상 단정 포함)
- clippy/fmt 클린

## Case 8: Rust KIS WebSocket — 스크립트 더블의 FIFO 함정

- Evidence: rust/lossfunction/src/kis/{ws.rs,ws_tests.rs}
- Confidence: 5/5

### Error
```
left: [81000, 80500]   # 스크립트 pop()이 LIFO라 연결1이 81000을 받음
left: [80500, 80500]   # first()+clone은 제거를 안 해 두 연결이 같은 스크립트 사용
```

- desired subscriptions은 BTreeSet(도메인 상태) — 재연결마다 정렬 순서로
  replay, 구독 누락 원천 차단. approval_key도 주입(provider)로 WS 토큰
  재발급 경로 열어둠.
- wiremock 테스트는 #[serial] + 서버 생존 유지(전 카드 교훈 즉시 적용).

### Verification
- `cargo test` → 95 passed × 3연속 (프레임 단일/복수/거부, 구독 형상,
  PINGPONG, 재연결+replay+시세 재개, unsubscribe 미재생, approval secretkey)

### 조사 요약 (범용 6분류 + 국내 적합성)
개인 자동매매의 실전 분포는 크게 6범주: 추세추종/모멘텀, 평균회귀, 브레이크아웃,
실행(VWAP/TWAP), 통계차익(페어), 팩터 로테이션. 국내 주식 특성:
- **상승장/하락장 비대칭**: 코스피는 장기 횡보+급락 국면 반복 — 순수 추세추종은
  횡보장에서 신호 빈발 손실. 평균회귀+브레이크아웃 혼합이 국내 개인권장.
- **거래세(매도 0.15%+커미션)**: 회전율 높은 단기 전략은 비용으로 잠식 —
  브레이크아웃/모멘텀 등 저빈도 신호 유리.
- **상하한가 30%/공매도 제약**: 하락 방향 헤지 부재 → 매도 후 현금 대기가
  기본. 그리드/물타기는 하락 국면 리스크 극대(국내 커뮤니티 다수 손실 사례).
- **시장 데이터**: 일봉+분봉으로 충분(고빈도 불가, API 레이트제한).

### 우선순위 5선정 (이미 3종 구현 완료 → 5종 신규 발행)
1. **볼린저 밴드 역추세**(평균회귀, 저빈도, 국내 횡보장 적합) — 구현 카드 발행
2. **12-1 모멘텀 로테이션**(월간 리밸런싱, 저빈도, 거래세 최소) — 카드 발행
3. **MACD 교차**(추세추종, SMA 교차 보완) — 카드 발행
4. **VWAP 실행 알고리즘**(대량 주문 분할, 리스크 계층과 직접 연동) — 카드 발행
5. **페어 트레이딩**(상관 종목 스프레드 회귀, 통계적 우위, 국내 대형주쌍 적용)
   — 조사 후보로 보류(데이터 요구 큼, 일봉 상관계수 산출 필요)

### 배제 근거
