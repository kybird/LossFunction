## Case 1: 라이브 봉 공급 부재 — HistoryWindow를 채우는 경로가 백테스터뿐

### Grounding
- Git Context: `hash:5d65ab6`
- Evidence: `rust/lossfunction/src/backtest.rs:243`(유일한 history.push 호출부), `rust/lossfunction/src/runtime/mod.rs:85`(on_quote는 최신가만 갱신), `data/*.db` candles 0행
- Confidence: 5/5

### Error
증상: 라이브/paper-kis 경로에서 룩백 전략(SMA 교차 등)이 과거 봉 없이 판단 불가.
`HistoryWindow`(전략용 완결 봉 종가 창, 기본 120봉)은 `TradingRuntime`에 존재하지만
이를 채우는 호출은 백테스터에만 있다.

### Environment Context
- 실시간 경로: KIS WS H0STCNT0 체결가(틱) → on_quote → 최신가 갱신. 틱→봉 집계기 없음.
- 과거 경로: KIS 기간별 시세 조회 클라이언트 없음, candles 테이블 0행.

### Analysis
- Root cause: 마이그레이션이 컴포넌트 패리티에 집중하느라 **데이터 공급 파이프**(틱→봉 집계,
  과거봉 조회·적재)가 카드로 존재하지 않았음. candles 스키마는 미리 설계돼 있었음.
- Impact: 백테스팅 엔진·데모 루프는 정상(합성 데이터). 라이브 전략 판단·MLP 학습 데이터가
  실데이터 기반으로 성립하려면 이 갭부터 메워야 함.
- 선행 순서: ① 일봉 백필(KIS 기간별 시세 or 외부 소스) → ② 틱→일봉 집계기 → ③ 라이브 전략/MLP.
  단, KIS 자격증명 없이도 ②는 완전 오프라인 개발 가능(데모 틱·테스트), ①도 KIS 클라이언트
  구현+wiremock 검증까지는 키 불필요 — 실데이터 적재만 대안 소스(Naver/KRX) 또는 키 대기.

  합성 데이터로만 녹색이면 라이브 판단 공백이 숨는다
