### Fix Code

  fail-loud는 **경계**(파싱·검증)에서, 런타임·저장 읽기는 살아남는 것이 이 프로젝트 원칙.

- Verification: **125 passed**(+2: 잘못된 인텐트 생존, 손상 타임스탬프→StorageError), clippy 0, fmt 클린.

### Design Decision
"스크립트는 까먹는다"는 문제의 구조적 해법으로 백필을 상태 페이지 버튼으로 이동.
kill-switch 제어 패턴(배포 계층 loopback·audit)을 그대로 준수. 백필은 읽기 전용+멱등이라
버튼 오남용이 안전하고, 종목별 마지막 봉 날짜 표시로 데이터 신선도가 스스로 보임.

### Analysis

- 테스트 함정: (1) oneshot 테스트에서 ConnectInfo 기반 요청 단위 loopback 검증은
  기존 controls에도 없는 새 메커니즘 — 배포 계층 패턴 유지로 AC 정정(노트 기록).
  (2) 오프라인 실패 경로는 base_url_override로 죽은 로컬 포트(127.0.0.1:9)를 찔러
  네트워크 없이 정착·audit·렌더까지 검증. (3) Arc<AppState> 수정은 get_mut 전 원본
  구성으로 — state() 헬퍼를 AppState 반환으로 리팩터.
- main --backfill-daily CLI는 run_backfill 공유 구현으로 통합(중복 제거).
- Verification: **132 passed**(+5), clippy 0, fmt, check_docs 9/9.
